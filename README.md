# NetGuard

## Descripción
NetGuard es un sistema de monitoreo y gestión de dispositivos de red orientado a pequeñas empresas. Su propósito es facilitar la supervisión del estado y disponibilidad de los dispositivos que forman parte de la infraestructura de red.

## Objetivo
Desarrollar una solución que permita monitorear y gestionar dispositivos de red de pequeñas empresas, facilitando la supervisión de su estado y disponibilidad.

## Herramientas utilizadas
- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- Git
- GitHub
- GitHub Projects
- SNMP
- SSH
